libfw

Dependency-free, embeddable C libraries for stateful L3/L4 network policy — a first-match ACL, connection tracking (conntrack) and an HCL front-end, extracted from socket_vmnet.

Documentation GitHub

libfw is the firewall core extracted from socket_vmnet's ACL work, packaged as a small, reusable C library. It matches and tracks raw ethernet frames (const uint8_t *frame, size_t len), so it has no dependency on any particular packet source — drive it from vmnet, TUN/TAP, pcap or a userspace proxy. The ACL is first-match-wins over ethernet / IPv4 / IPv6 / TCP / UDP / ICMP; conntrack lets the return traffic of an allowed flow pass without an explicit reverse rule, with caller-supplied time so it is deterministic and unit-testable.

No vendored dependencies. Policies load from a compact JSON ruleset via a tiny built-in parser, or from HCL through the libhcl/c-hcl submodule (the declarative subset of HCL — attributes and labeled blocks, no expressions or interpolation). Everything builds from source; the only third-party code is the optional c-hcl submodule. BSD-3-Clause throughout.
